\section{ساخت، پروگرام و تولید مجدد}
\subsection{پلتفرم توسعه}
PlatformIO را نصب و پوشهٔ مستقل پروژه را باز کنید. نسخهٔ پلتفرم مشخص شده و
فایل‌های سازنده از داخل پروژه ساخته می‌شوند. نام برد ارزیابی فقط مشخصات میکرو
و پروگرامر را فراهم می‌کند و به معنی یکسان‌بودن برد سفارشی نیست.
\begin{LTR}
\begin{lstlisting}[language={}]
pio run
pio run -e stm32f107vc_stlink
pio run -t upload
pio run -e stm32f107vc_stlink -t upload
\end{lstlisting}
\end{LTR}
هر دو محیط منابع مشترک و لینک‌اسکریپت ۲۵۶ کیلوبایت فلش را دارند. نصب اولیه
ابزارها به دانلود نیاز دارد ولی فایل پروژه از پوشهٔ همسایه نمی‌خواند.

\subsection{توسعه با کیل}
فایل پروژهٔ داخل MDK را باز کنید. پکیج میکرو و کامپایلر نسخهٔ شش را نصب کنید.
پروگرامر SWD و الگوریتم فلش ۲۵۶ کیلوبایت را در تنظیمات دیباگ و ابزارها انتخاب
و Build و Download کنید. آرایه‌های آدرس، دما و وضعیت و شمارندهٔ چرخه را در Watch
ببینید. XML و عضویت فایل‌ها بررسی شده‌اند؛ ساخت واقعی Keil انجام نشده است.

\subsection{بازسازی بدون ازبین‌رفتن کتابخانه}
فایل تنظیم CubeMX را باز و کلاک، پایهٔ open-drain و حفظ کد کاربر را نگه دارید.
کتابخانه و برنامه بیرون از Core هستند و include و فراخوانی‌ها در بلوک‌های
کاربر قرار دارند. مولد ممکن است پروژهٔ Keil را بازنویسی کند؛ اسکریپت پس‌تولید
عضویت فایل‌ها و مسیرها را برمی‌گرداند. اگر مسیر نسبی شناخته نشد، فایل cmd را
در تنظیمات User Actions صریح انتخاب کنید. پس از هر تولید اجرا کنید:
\begin{LTR}
\begin{lstlisting}[language={}]
python tools/sync_keil.py
python tools/check_project.py
pio run
\end{lstlisting}
\end{LTR}
همگام‌سازی تکرارپذیر است و فایل شروع، اندازهٔ فلش و منابع برنامه، کتابخانه و
HAL را بازمی‌گرداند. مسیر Inc کتابخانهٔ تازه را به PlatformIO اضافه کنید.
افزودن peripheral به بررسی هدر HAL، وقفه و MSP هم نیاز دارد. تغییرات را مرور
و Keil را نیز بسازید. تولید واقعی CubeMX در این محیط انجام نشده است.

\subsection{پروژهٔ بعدی}
کل قالب خام را کپی کنید. فقط کلاک، SWD، فایل شروع، پشتیبانی سازنده و توابع خالی
برنامه دارد. نام پروژه را در CubeMX تغییر دهید، sync را اجرا کنید و کتابخانه
و پایهٔ قطعهٔ بعدی را اضافه کنید. وضعیت و گزارش دو زبان همان پروژه را بنویسید
و وابستگی‌ها را داخل همان پوشه حفظ کنید.
