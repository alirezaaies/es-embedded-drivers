# Driver location / محل کتابخانه‌ها

Put each portable driver in Name/Inc and Name/Src. Add its include path to
PlatformIO and run tools/sync_keil.py. Keep MCU adapters in Application.

هر کتابخانه را در پوشهٔ مستقل با Inc و Src قرار دهید. مسیر include را به
PlatformIO اضافه و اسکریپت همگام‌سازی Keil را اجرا کنید. لایهٔ میکرو در Application است.
